# grund

**The boring production layer for your own servers.**

Kubernetes' guarantees with compose's effort, on a handful of dedicated
servers you own. Every guarantee comes with evidence: when the last restore
drill ran, when the last failover drill ran, how old the newest backup is.
If we disappear, you keep a standard k3s cluster with its manifests in your
own git.

- Website: <https://grund.run>
- Source of truth: <https://git.kjuulh.io/grund>. The repositories here are
  push mirrors of it.

*Early days. Nothing here is ready for production yet.*
